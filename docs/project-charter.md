# Academix – Project Charter

## Project Title

**Academix – AI-Powered Academic Knowledge Assistant**

---

## Guide

**Project Guide:** Prasenjit B

---

## Problem Statement

Students spend significant time searching through multiple academic documents such as regulations, lecture notes, timetables, and previous question papers to find relevant information. A unified conversational system can reduce this effort and improve access to academic knowledge.

---

## Objectives

* Build an AI-powered academic assistant for IIIT Sri City.
* Implement Retrieval-Augmented Generation (RAG) for document-based question answering.
* Support authenticated manual document uploads.
* Provide role-based access for Students, Faculty, and Admin users.

---

## Initial Scope

* IIIT Sri City only
* PDF/document upload
* Document indexing and retrieval
* Conversational academic query support
* Chat history and source-aware responses

---

## Deliverables

* Frontend application
* Backend APIs
* Authentication module
* RAG pipeline
* Vector database integration
* Documentation and weekly progress reports

---

## Development Methodology

The project will follow an **incremental development approach** with weekly progress tracking, GitHub version control, and periodic faculty review meetings.
